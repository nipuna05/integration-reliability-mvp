Import from curl (fastest way to start)

Paste a curl command for an API you already use (from its docs, Postman or the browser's Network tab, "Copy as cURL"). The app calls it once, shows the result, hides any API key as a secret, and builds the check.

Edit checks (JSON)

Each check has steps (url, method, body, expect, extract). Use {{base}}, {{runId}} and extracted variables in URLs/bodies. "Test" runs without saving or recording.

Secrets (API keys)

Stored on the server only; values are never shown again. Use in a check as {{secret.NAME}}, e.g. "headers": { "authorization": "Bearer {{secret.PAYROLL_TOKEN}}" }.
